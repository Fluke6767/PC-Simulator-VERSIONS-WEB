# PC Simulator VERSIONS WEB
Open-source 3D PC building & Bitcoin mining sandbox (Three.js + Vite + TypeScript). Code: MIT.

## Run
    npm install
    npm run dev     # dev server
    npm run build   # production build -> dist/

## Status
Phase 1 (Core): 3D engine, game loop, main menu, settings (auto-saved), world creation (3 maps), first-person player (WASD/Shift/Space), pause.
Next: touch controls, Phase 2 (grab / inspect / placement / inventory / hamburger menu).

## Structure
src/core engine, src/player, src/world, src/ui, src/localization, data/ JSON content, mods/, docs/
